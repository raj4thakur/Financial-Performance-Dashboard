# 💹 Financial Performance Dashboard

An interactive dashboard to visualize financial KPIs such as revenue, expenses, and profit trends.

## 🚀 Tech Stack
- **Python**
- **Streamlit** (for UI)
- **Plotly** (for interactive charts)
- **Pandas** (for data handling)
- **Render** (for deployment)

## 📊 Features
- Filter by Region
- Monthly Revenue vs Expenses vs Profit Trends
- Regional Financial Summary
- Profit Margin Analysis
